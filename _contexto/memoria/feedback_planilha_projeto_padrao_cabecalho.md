Quando o usuário for elaborar uma planilha "em formato de projeto" (como a planilha "teste mapeamento de aulas" em [[project_projetos_planilha_mapeamento_aulas]]), o padrão de layout é:

- Linhas 1 a 9: reservadas para design da página / outros cabeçalhos (título, identidade visual, instruções etc.)
- Linha 10: cabeçalho das colunas principais (nomes das colunas de dados)
- Linha 11 em diante: os dados em si

**Why:** o usuário definiu essa padronização explicitamente para separar o "design" da planilha (topo) da tabela de dados propriamente dita, e quer reaplicar isso em outras planilhas do mesmo formato.

**How to apply:** antes de criar ou estruturar uma nova planilha "em formato de projeto" (não confundir com planilhas simples de uso único), perguntar ao usuário se ele quer seguir esse padrão (cabeçalho na linha 10, dados a partir da 11) antes de montar a estrutura.
